# Cafe Sales Analysis

## โจทย์ (Problem Statement)

วิเคราะห์ยอดขายของร้านกาแฟเพื่อระบุแนวโน้มการซื้อของลูกค้า ช่วงเวลาที่มียอดขายสูงสุด และปัจจัยที่ส่งผลต่อรายได้ โดยมีเป้าหมายเพื่อใช้เป็นข้อมูลในการปรับปรุงเมนู การจัดกำลังพนักงาน และการดำเนินธุรกิจให้มีประสิทธิภาพมากขึ้น

## ข้อมูล (Data)

- **ที่มา:** ข้อมูลจำลองการขายร้านกาแฟสำหรับพอร์ตโฟลิโอ (October 1-16, 2026)
- **ลักษณะข้อมูล:** ข้อมูลการสั่งอาหารและเครื่องดื่มในร้านกาแฟประกอบด้วย 3 ตาราง: menu (รายการอาหาร), orders (ใบสั่งซื้อ), order_items (สินค้าในแต่ละใบสั่ง)
- **จำนวนรายการ:** 504 ใบเสร็จ (343 ใบมีรายการ 1-3 รายการ รวม 504 รายการ) บน 16 วัน (1-16 ต.ค. 2026)
- **ฟิลด์สำคัญ:** order_id, item_id, item_name, category, quantity, unit_price, total_sales, payment_method, datetime

## เครื่องมือที่ใช้ (Tools)

- SQL - สำหรับการจัดเตรียมและวิเคราะห์ข้อมูล

## ไฟล์ในโฟลเดอร์ (Files)

- `cafe_data_setup.sql` - สคริปต์ SQL สำหรับเตรียมข้อมูล
- `cafe_analysis.sql` - สคริปต์ SQL สำหรับการวิเคราะห์

## ข้อค้นพบ (Key Findings)

1. **ช่วงเช้ามีธุรกรรมมากที่สุด** - ช่วงเวลา 07:00-09:59 น. มี 31% ของจำนวนบิลทั้งหมด
2. **เครื่องดื่มสร้างรายได้หลัก** - เครื่องดื่ม (กาแฟ ชา และเครื่องดื่มพิเศษ) คิดเป็น 62% ของรายได้ทั้งหมด ขณะที่อาหารคิดเป็น 38%

## ข้อจำกัด (Limitations)

- ข้อมูลนี้เป็นข้อมูลจำลองสำหรับพอร์ตโฟลิโอ ไม่ได้มาจากร้านกาแฟจริง
- ยังไม่มีข้อมูลลักษณะลูกค้า (Customer demographics) และข้อมูลสมาชิกสะสมแต้ม
- ไม่ครอบคลุมปัจจัยด้านฤดูกาล โปรโมชั่น หรือเหตุการณ์พิเศษในช่วงเวลาที่วิเคราะห์
