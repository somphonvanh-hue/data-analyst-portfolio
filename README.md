# Data Analyst Portfolio

สวัสดีครับ ผม Nynon นักวิเคราะห์ข้อมูล ใช้ SQL, Python และ Looker Studio วิเคราะห์ข้อมูลและสร้างแดชบอร์ดเพื่อสนับสนุนการตัดสินใจ

ความสนใจ: การวิเคราะห์ธุรกิจ, การค้นหาแนวโน้มจากข้อมูล และการสร้างแดชบอร์ดเพื่อสนับสนุนการตัดสินใจ

ข้อมูลในพอร์ตโฟลิโอนี้เป็นข้อมูลจำลอง/สังเคราะห์เพื่อการฝึกวิเคราะห์เท่านั้น

## โปรเจกต์

- [HR Attrition](hr-attrition/): การวิเคราะห์อัตราการลาออกของพนักงานจากชุดข้อมูล HRDataset_v14 พบว่าพนักงานที่จ้างในปี 2011 มีอัตราการลาออกสูงถึง 71.08% ส่งผลให้อัตราการลาออกรวมอยู่ที่ 33.4%
- [Cafe Sales](cafe-sales/): การวิเคราะห์ยอดขายร้านกาแฟจากข้อมูลจำลอง 504 รายการใน 343 บิลบน 16 วัน (1-16 ต.ค. 2026) พบว่าช่วงเช้า 07:00-09:59 น. มี 31% ของบิล และเครื่องดื่มคิดเป็น 62% ของรายได้
